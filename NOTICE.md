## BFAM-Net Reconstruction

The BFAM-Net-specific files and configuration were organized from the supplied
manuscript, the supplied experiment directory, and the three supplied local
reference papers. The original experiment directory did not expose final
`BFRE`, `BCFM`, or `CSCG` classes under those names. The repository therefore
contains a cleaned reconstruction of the final interfaces and documents that
boundary in the README files.

The supplied reference papers are not redistributed here. Their bibliographic
records are listed in the README files for attribution and implementation
context.
